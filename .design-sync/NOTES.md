# design-sync notes

Waypoint is a Next.js app, not a component library: it has no `dist/` and no compiled types. The sync treats the Storybook (`.storybook/`) as the source and bundles the components through `.design-sync/entry.js`.

## Fixes

- [GENERAL] Converter found 0 exports -> the components are plain JS with no `.d.ts` -> hand-written contracts in `.design-sync/index.d.ts`, wired through `package.json` `types`. Add an interface and a `declare function` there for each component added to `entry.js`.
- [GENERAL] Storyblok SDK in the bundle -> `.design-sync/tsconfig.json` maps `@storyblok/react/rsc` to `.storybook/mocks/storyblok.jsx`, the same mock `.storybook/main.js` aliases, so bundle and reference render the same thing.
- [GENERAL] Story previews failed to load fixtures -> `.storybook/fixtures.js` used Vite's `import.meta.glob`, which esbuild doesn't compile -> fixtures come from `.storybook/fixtures.data.json`, generated by `npm run storybook:fixtures` (cfg.buildCmd). Run it before every converter build.
- [GENERAL] Every font fell back (Arial Narrow, Georgia) -> next/font sets `--font-next-*` and its `@font-face` at runtime, so the scraped Storybook CSS had neither -> `.storybook/fonts.css` loads the same Google families and defines the variables statically. Storybook no longer uses next/font.
- [GENERAL] Inherited text was black in previews, ink in Storybook -> the page defaults lived on `<body>` -> `SiteRoot` (`.design-sync/SiteRoot.jsx`) carries the layout.js root classes; the Storybook decorator and `cfg.provider` both use it. A decorator in `preview.jsx` alone failed to bundle (`Could not resolve "tailwindcss"` from the globals.css import).

## Re-sync risks

- `.design-sync/index.d.ts` is hand-written. A prop added to a component doesn't reach Claude Design until someone adds it there.
- `SiteRoot` and `.storybook/fonts.css` copy the root classes and font weights from `src/app/layout.js`. A change to layout.js needs the same change in both.
- Fonts load from fonts.googleapis.com at runtime (`[FONT_REMOTE]`), and photos from a.storyblok.com. Both need network access in Claude Design and during compare.
- The bundle CSS is scraped from the Storybook build (`[CSS_FROM_STORYBOOK]`), so it holds only the Tailwind classes the scanned sources use. Rebuild the reference after adding components or classes.
- Spike scope: only Button and DestinationCard have stories.
